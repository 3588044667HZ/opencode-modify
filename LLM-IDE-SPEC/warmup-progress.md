### 目标

OC Desktop 接入预热进度条。

### 行为

- IntelliJ 启动后，OC 订阅 `indexing` 事件
- 状态栏显示进度条，类似 IDEA“正在分析项目...”
- 进度条显示：`正在分析项目... 40% (engine.ts)`
- 预热期间用户可提问，请求进入队列
- 预热完成后进度条消失，队列自动执行
- 预热失败：显示“语义引擎启动失败”，队列降级到文本层，触发响铃

### UI 位置

底部状态栏，非阻塞，不打断输入。

### 验收标准

- [ ] 预热期间进度条可见
- [ ] 进度百分比正确更新
- [ ] 预热期间提问进入队列
- [ ] 预热完成后进度条消失
- [ ] 队列请求自动执行
- [ ] 预热失败时降级 + 响铃

---

## 实现顺序

```
1. intellij-headless 骨架 + ping 方法
2. jsonrpc-channel（OC 客户端 + IntelliJ server）
3. adapter-layer 的 read_view
4. oc-render-layer
5. warmup-progress
```

前两步跑通后，第三步是核心——它验证 IntelliJ 语义引擎能否产出我们需要的数据。第四步验证渲染层翻译。第五步是体验层。
